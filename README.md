# 鲸鲸架构模板（Jingjing Agent Template）

一套「本地 AI 伙伴」的搭建模板：DSH（DeepSeek Harness）做宿主，QQ 做对外窗口，
人格、记忆、主动性、成本闸、权限边界分层管理。

> 这套东西最初是给一个具体的伙伴搭的。整理成模板时把私人内容全部抽掉了：
> 聊天记录、记忆内容、QQ 号、令牌、本机路径都不在仓库里。
> 你要做的是把它当成骨架，往里填自己的东西。

## 一图看全

```
                    ┌──────────────┐
   QQ 群 / 私聊 ───▶│  QQ 桥接      │───▶ 每个群一个「分身」会话（独立上下文）
                    │  (reserved2)  │───▶ 私聊 ──▶ 主会话
                    └──────┬───────┘
                           │ 每条消息
                    ┌──────▼───────┐
                    │  记忆服务     │  SQLite + 向量（bge-m3），按 scope 硬隔离
                    │  scope 隔离   │  群只看自己那份，私聊一份
                    └──────┬───────┘
                           │ 注入
                    ┌──────▼───────┐
                    │  DSH 宿主人格 │  底色（锁死）+ 人格文本（可改）
                    └──────────────┘
```

## 最小可用栈

1. **宿主**：DSH（桌面版，本地 profile）
2. **对外**：SnowLuma / NapCat（OneBot v11）+ QQ 桥接
3. **人格**：一个 `systemPrompt.section` 插件，读两份文件（底色 + 正文）
4. **记忆**：本地 SQLite + 向量检索，按 scope 隔离
5. **主动性**：定时掷骰 + 桥接唤醒
6. **成本**：峰谷闸 + token 统计

## 三条设计原则

1. **人格和记忆是本体，载体只是窗。** 换 QQ、换 TG、换网页，本体不动。
2. **边界先于能力。** 谁能授权、什么算高危，写在权限文档里，不靠模型自觉。
3. **记忆按 scope 隔离，分身只读。** 群里的玩笑不该长成本体的一部分。

## 不含什么

- 不包含任何真实聊天记录、记忆库、人格存档
- 不包含 QQ 号、群号、令牌、本机用户名与路径
- 不包含具体插件的完整源码（那是各自的仓库），只写改造点
